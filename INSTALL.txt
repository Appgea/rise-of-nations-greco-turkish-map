Greco-Turkish War - Rise of Nations: Extended Edition map  (v1.1)

INSTALL
Extract all four folders into your game folder under scenario\Custom\
(Steam > Rise of Nations > Manage > Browse local files), so you get e.g.
  scenario\Custom\GrecoTurkish_Frontier\GrecoTurkish_Frontier.scx

SOLO (against the computer)
Solo Game > Load a Scenario > GrecoTurkish_Frontier_vsAI or GrecoTurkish_Capitals_vsAI.

MULTIPLAYER (online through Steam, no shared network needed)
Both players install the same files and update the game.
Host: Multiplayer > Online > create game > Game Rules: Scenario > GrecoTurkish_Frontier or _Capitals.
Slot 1 = Greeks, slot 2 = Turks.

More: https://github.com/Appgea/rise-of-nations-greco-turkish-map
